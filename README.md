# ⚾ KBO Card Collection

2026 KBO 오피셜 컬렉션 카드+ 카드 도감. 카드 사진과 보유·교환 정보를 관리합니다.

- `images/`: 카드별 크롭 사진 (신규 사진은 별도 파일명으로 추가)
- `data/cards.json`: 카드 보유·거래완료 상태, 선수명·구단·등번호·종류
- `data/trades.json`: 교환 기록. 날짜, 준 카드·받은 카드, 각 수량 기록
- `index.html`: 카드목록·거래내역 탭과 검색 필터 (거래내역은 준 카드·받은 카드 사진을 좌우로 표시)

## 교환 운영 원칙

- 당분간 **일반형 카드만 교환 대상으로 사용**합니다. 기록형·홀로 등 다른 종류는 명시적인 확인 없이 거래완료 처리하지 않습니다.
- 준 카드는 선수명·구단·등번호로 확인하고, 중복 종류가 있다면 정확한 카드를 지정합니다.
- 받은 카드는 사진으로 선수명·구단·등번호·카드 종류를 확인합니다.
- 기존 이미지는 재사용하고, 새 이미지 파일만 추가해 Git 이력의 불필요한 증가를 줄입니다.
- 교환 기록에는 금액이나 수익을 저장하지 않습니다.

**주의:** 홀로 및 기록형 디자인은 잠정 분류이며, 사진이 일부 기울어져 바인더 가장자리가 보일 수 있습니다. 원본 사진이나 개인정보는 포함하지 않았습니다. 카드 판매·수익 정보는 수집하지 않습니다.

## 카드 종류 분류 기준 (2026 KBO)

- 노멀: 일반 선수 카드 (2026 기본 제품의 홈/어웨이 버전 구분은 별도 속성으로 관리 가능)
- 레코드: 선수 기록을 다룬 카드 (PLUS 제품군에서 사용)
- 홀로: 홀로그램 처리 카드
- 홀로 패러렐: 홀로와 별도 구분되는 변형 카드. 정확한 종류는 뒷면과 실물 가공을 확인한 뒤 분류
- 알파벳: 구단명 완성을 위한 알파벳 카드
- 승리부적: 승리부적 콘셉트 카드
- 사인: 사인 카드 (인쇄 사인과 실제 친필 사인을 혼동하지 않도록 확인)
- 분류 미확인: 공식 카드 유형이 아닌 관리용 상태. 사진만으로 종류를 확정하지 못할 때 사용

이전의 임의 명칭 `일반 디자인`, `기록형 디자인`, `특수 디자인`, `세로형 디자인`은 카드 종류 필드에서 사용하지 않습니다. **두산 박지훈(P06-02)은 홀로**로 확정했습니다. 김서현(P07-01)과 김동주(P07-02)는 이름 배치가 세로형이지만 공식 등급이 확정되지 않아 `분류 미확인`으로 두었습니다.
