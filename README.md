# ⚾ KBO Card Collection

2026 KBO 오피셜 컬렉션 카드+ 카드 도감. 카드 사진과 보유·교환 정보를 관리합니다.

- `images/`: 카드별 크롭 사진 (신규 사진은 별도 파일명으로 추가)
- `data/cards.json`: 카드 보유·거래완료 상태, 선수명·구단·등번호·종류
- `data/trades.json`: 교환 기록. 날짜, 준 카드·받은 카드, 각 수량 기록
- `index.html`: 카드목록·거래내역·거래카드목록과 검색 필터

## 교환 운영 원칙

- 당분간 **일반형 카드만 교환 대상으로 사용**합니다. 기록형·홀로 등 다른 종류는 명시적인 확인 없이 거래완료 처리하지 않습니다.
- 준 카드는 선수명·구단·등번호로 확인하고, 중복 종류가 있다면 정확한 카드를 지정합니다.
- 받은 카드는 사진으로 선수명·구단·등번호·카드 종류를 확인합니다.
- 기존 이미지는 재사용하고, 새 이미지 파일만 추가해 Git 이력의 불필요한 증가를 줄입니다.
- 교환 기록에는 금액이나 수익을 저장하지 않습니다.

**주의:** 홀로 및 기록형 디자인은 잠정 분류이며, 사진이 일부 기울어져 바인더 가장자리가 보일 수 있습니다. 원본 사진이나 개인정보는 포함하지 않았습니다. 카드 판매·수익 정보는 수집하지 않습니다.
