# ⚾ KBO Card Collection

2026 KBO Official Collection Card+ 사진 기반 카드 도감.

## 관리 방식
- 교환하거나 새 카드를 개봉한 뒤 바인더 전체 사진을 촬영합니다.
- 사진에서 현재 보유 카드를 다시 확인하여 `data/cards.json`을 갱신합니다.
- 교환 전후 확인된 내역은 `data/trades.json`에 별도로 기록합니다.
- 판매금액, 구매원가 및 수익 계산은 포함하지 않습니다.

## 현재 기준
- 이전 대화에서 바인더 사진 5페이지, 카드 45장을 확인했습니다.
- 홀로 후보 3장: 김웅빈, 김한별, 김민혁.
- 선수명과 등급은 사진 기반 잠정 판정이며 추가 검수가 필요합니다.
- 전체 원본 사진 대신 각 카드만 분리한 이미지를 사용합니다.

## 개인정보 및 공개 주의
저장소는 **Private**로 유지합니다. 학생·학부모 이름, 연락처, 교환 상대 개인정보를 기록하지 않습니다.
카드 사진 공개 전 저작권과 배경 노출을 검토합니다.

## 파일
- `data/cards.json`: 보유 카드 목록
- `data/trades.json`: 카드 교환 기록
- `images/`: 개별 카드 사진 (추후 등록)
