# ⚾ KBO Card Collection

2026 KBO 오피셜 컬렉션 카드+ 카드 도감. 바인더 5페이지의 카드 45장 사진을 각 칸별로 다시 잘랐습니다.

- `images/`: 카드별 크롭 사진 45장 (원본 EXIF 제외)
- `data/cards.json`: 현재 보유 카드 목록 (사진 기반 잠정 식별)
- `data/trades.json`: 교환 기록. 교환 날짜와 주고받은 카드만 기록
- `index.html`: 카드 검색 및 구단·종류별 필터

**주의:** 홀로 및 기록형 디자인은 잠정 분류이며, 사진이 일부 기울어져 바인더 가장자리가 보일 수 있습니다. 원본 사진이나 개인정보는 포함하지 않았습니다. 카드 판매·수익 정보는 수집하지 않습니다.
