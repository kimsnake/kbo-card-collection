# ⚾ KBO Card Collection

2026 KBO Official Collection Card+ 사진 기반 카드 도감 (비공개).

## 관리
- 카드 사진 45장과 선수·구단·종류 목록을 정리합니다.
- 새 사진으로 교환 전후 보유 목록을 갱신합니다.
- `data/trades.json`에 교환 내역을 별도로 기록합니다.
- 금액 및 수익 정보는 기록하지 않습니다.

## 사진 상태
기존 카드 크롭 이미지의 위치가 일부 잘못되어 **수정본 파일을 별도로 생성했습니다.** GitHub 저장소에는 현재 이미지 업로드가 아직 완료되지 않았습니다. 수정된 `images/` 폴더를 업로드해야 카드 도감에서 사진을 확인할 수 있습니다.

## 개인정보
학생·학부모 정보는 기록하지 않습니다. 원본 바인더 사진에는 주변 공간 및 신체 일부가 보여 업로드 대상에서 제외했습니다. 저장소를 공개로 변경하기 전에 사진과 권리 관계를 확인하세요.
