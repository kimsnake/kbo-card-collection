# ⚾ KBO Card Collection

2026 KBO 오피셜 컬렉션 카드+ — 개인 카드 도감.

- `index.html`: 카드 사진, 선수·구단 검색, 카드 종류 필터
- `images/`: 카드별 이미지 45장
- `data/cards.json` / `data/cards.csv`: 현재 소장 카드 목록 (잠정 판정)
- `data/trades.json`: 별도 교환 기록 (초기 빈 목록)

**공개 전 주의:** 이미지는 카드 부분만 잘랐지만, 공개 여부와 사진 사용권을 직접 확인하세요. 학생 및 학부모 개인정보는 저장하지 마세요.
